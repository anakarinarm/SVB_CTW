# `SVB_CTW`

> Written by Claude, approved by KRM.

MITgcm experiments on coastal-trapped waves (CTW) generated by a wind pulse at
Sebastián Vizcaíno Bay (SVB), rerun with controlled bathymetries for the
manuscript revision. The design and requirements for the reruns are in
`README_CODEX_CTW_RERUNS.md`.

This repository holds the model configuration only: code modifications,
namelists, input-generation, run and analysis scripts. MITgcm itself is not
included (see [Reproducing the runs](#reproducing-the-runs)), and neither are
the input binaries or the model output.

Until 2026-10-29 this lived in `verification/CTW_SVB` of a personal MITgcm
fork; the history of that folder was carried over. Superseded configurations
are in `archive/` (see `archive/README.md`).

  CTW_smooth70_bathymetry_package/         smooth70 bathymetry package
  common_input_512x612/                    original-domain 16-day wind and OBCS T/S files
  telescoped_west64_south72/               final-domain inputs (built from the two above)

The final configuration's folder keeps its long name because the LaCie run
folders link back to it by absolute path.

## Final configuration

Details are in
`ctw_reruns_telescoped_west64_south72/README.md` and
`ctw_reruns_telescoped_west64_south72/model_configuration_summary/` (README
and PDF with figures).

- **Grid:** `576 x 684 x 100`, spherical polar. It is the approved
  `512 x 612` grid plus 64 telescoped columns to the west and 72 rows to the
  south (flat 4400 m buffer). The vertical grid has 100 levels, 4700 m deep.
- **Open boundaries:** W/S/N with Orlanski radiation and a 48-cell linear
  momentum sponge, which lies entirely outside the original domain on the W
  and S sides. No T/S sponge. East is closed.
- **Forcing:** the original upwelling-favourable wind pulse (peak
  0.089 N/m², at hour 3), tapered to zero in the buffers. Initial T/S are
  horizontally uniform February 2008 profiles, which are also prescribed at
  the OBs.
- **Run:** from rest, 15 days, `deltaT = 60 s`, 16 MPI ranks (4 x 4).
- **Diagnostics (MDS binary):** 20-min averages of
  `UVEL, VVEL, WVEL, RHOAnoma, PHIHYD` on 75 levels (`dyn3d_avg`), plus
  20-min averages and snapshots of `ETAN, PHI_SURF` (`surf_avg`,
  `surf_snap`). That is about 1.3 TB per 15-day case.
- **Executable:** `ctw_reruns_telescoped_west64_south72/build_binary/mitgcmuv`
  (`build/mitgcmuv` links to it), built from
  `code_telescoped_west64_south72_noexch2` with `-mpi`.

## Experiments

Every case shares the executable, grid, stratification and diagnostics. The
local folder holds the namelists. The model ran in the LaCie folder
(`/Volumes/LaCie/CTW_SVB_reruns_telescoped_west64_south72/<LaCie name>`),
whose `data*` files link back to the local folder. Some LaCie folders were
renamed after the run.

| Local folder | LaCie folder | Bathymetry / change | Length | Finished | Raw output on LaCie | Processed (`/Volumes/LaCie/AmeliaProcessedOutput/`) |
|---|---|---|---|---|---|---|
| `Rplus` | `Rplus` | realistic, with SVB | 15 d | 2026-07-31 | kept (1.3 TB) | `R/` |
| `Rminus` | `Rminus` | realistic, SVB removed | 15 d | 2026-08-01 | kept (1.3 TB) | `R/` |
| `Splus` | `S30plus` | 30-km smoothing, with SVB | 15 d | 2026-08-01 | not kept | `S30/` |
| `Sminus` | `S30minus` | 30-km smoothing, SVB removed | 15 d | 2026-08-02 | not kept | `S30/` |
| `S50plus` / `S50minus` | same | 50-km smoothing ± SVB | 15 d | 2026-08-05 / 08-10 | not kept | `S50/` |
| `S70plus` / `S70minus` | same | 70-km smoothing ± SVB | 15 d | 2026-08-18 / 08-19 | not kept | `S70/` |
| `Rplus_G5d` / `Rminus_G5d` | `R_G5dplus` / `R_G5dminus` | realistic ± SVB, 5-day Gaussian wind (`gaussian5d_review/`) | 30 d | 2026-10-07 / 10-08 | not kept | `R_G5d/` |
| `Rplus_50L` | `R50Lplus` | realistic with a smaller SVB (`bathy_realistic_SVB50L_mouth`); pair it with `Rminus` | 15 d | 2026-10-13 | not kept | `R50L/` |

All of these runs ended with `Execution ended Normally`. "Not kept" means
that only the logs (and, where present, the grid files and the last
`pickup.ckptA/B`) remain on LaCie. The raw output of the S runs and of
`R_G5dminus` was deleted before 2026-10-29, and that of `R_G5dplus` and
`R50Lplus` was deleted on 2026-10-29 (`archive/cleanup_ctw_svb_20261029.py`). Rerunning any case
regenerates it exactly (same executable and inputs).

Other folders in the final configuration:

- `smoke_Rplus`: the 20-minute smoke test of the final setup. Its output was
  removed; namelists, `STDOUT.0000` and `available_diagnostics.log` are kept.
- `smoke_Rplus_50L_hfac`: a 5-step hFac check of the 50L bathymetry
  (`hfac_review/`).
- `west_south_input/`: links to `input/telescoped_west64_south72/`, plus the
  50L bathymetry and the script that built it (`build_SVB50L_mouth_v2.py`).
- `gaussian5d_input/`: the 31-day Gaussian wind and OBCS T/S files (13 GB),
  built by `scripts/setup_gaussian5d_sensitivity.py`.
- `qc_animations/`: QC movies of all runs (`*.mp4`, not in git).
- `production_grid_bathymetries.nc`, `CTW_final_bathymetries_*.nc`: model
  grid and bathymetries as NetCDF for analysis.

## Reproducing the runs

1. **MITgcm.** Clone MITgcm and check out the version used for all runs,
   `checkpoint69k-11-gdecd05a68` (2026-02-12):

   ```bash
   git clone https://github.com/MITgcm/MITgcm.git
   git -C MITgcm checkout decd05a68a16c9a10b05da054f140886b217a441
   ```

   No MITgcm source file is modified; all changes are in
   `code_telescoped_west64_south72_noexch2/`.
2. **Build.** `MITGCM_ROOT=/path/to/MITgcm ./build.sh` writes
   `ctw_reruns_telescoped_west64_south72/build_binary/mitgcmuv`. The original
   runs used `build_options/darwin_arm64_gfortran_krm` (Homebrew GCC/gfortran
   15.2.0, MPICH, macOS 15 on Apple silicon); on another system pass a
   suitable optfile with `OPTFILE=...`. 16 MPI ranks (4 x 4) are required.
3. **Inputs.** The binaries are not in git. The approved 512 x 612
   bathymetries (`input/*_FINAL.bin`) come from
   `scripts/CTW_build_final_bathymetries.py`; the original-domain forcing and
   T/S (`input/common_input_512x612`) from the scripts listed below, starting
   from the original files referenced by `real_SVB/data`; and the final-domain
   inputs from `scripts/make_telescoped_west64_south72_inputs.py`.
4. **Run.** Each run folder in `ctw_reruns_telescoped_west64_south72/` holds
   the namelists of one experiment. Run `mpirun -np 16 ./mitgcmuv` in a folder
   that contains (or links to) those namelists, `mitgcmuv` and
   `west_south_input/`; `scripts/prepare_external_output_dirs.py` sets up such
   folders on an external drive. Allow about 1.3 TB per 15-day case.

Check on 2026-10-29: rebuilding with `build.sh` from MITgcm `decd05a68` in
this repository reproduced the preprocessed Fortran sources of the executable
used for the runs (see the log at the end of this file).

## Practical notes

- Python: a conda/miniforge environment with MITgcmutils, xarray, netCDF4,
  matplotlib and cmocean.
- New case: copy a run folder, change the namelist, create its external
  folder with `prepare_external_output_dirs.py`, and run there.
- Git tracks namelists, code, scripts and READMEs. Binaries, output, builds,
  figures, PDFs and movies are excluded (`.gitignore`).
